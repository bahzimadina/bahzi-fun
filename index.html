      FAQ

      Apakah OmniTools gratis?
      Ya, tidak ada paket berbayar di halaman ini dan tidak perlu bikin akun.
      Apakah file saya diunggah ke server?
      Khusus penggabung PDF, ya: berkas dikirim ke server untuk digabung di memori lalu dihapus setelah selesai, tidak ditulis ke disk. Alat lain belum bisa dipakai, jadi belum ada yang diunggah.
      Bisakah saya self-host?
      Belum bisa. Rencananya nanti bisa dijalankan sendiri lewat container.
      Kapan rilis?
      Dirilis bertahap, belum ada tanggal pasti.
      Kenapa gabungan PDF saya gagal?
      Biasanya karena salah satu dari ini: berkas terkunci kata sandi, berkas rusak atau bukan benar-benar PDF, jumlah halaman melebihi 200, jumlah berkas lebih dari 10, atau total ukuran di atas 25 MB. Pesan galat dari server akan muncul di panel alat.
