FAQ

Apakah OmniTools gratis?
Ya, alat inti direncanakan gratis. Halaman ini adalah demo, belum ada paket berbayar.
Apakah file saya diunggah ke server?
Tidak. Pemrosesan terjadi di browser; berkas tidak meninggalkan perangkatmu.
Bisakah saya self-host?
Rencananya bisa, lewat image container yang ringan. Saat ini belum tersedia.
Kapan rilis?
Bertahap sesuai roadmap; belum ada tanggal pasti — halaman ini masih demo.
Ada API-nya?
Belum. API publik direncanakan di Fase 3 dan masih dievaluasi.
